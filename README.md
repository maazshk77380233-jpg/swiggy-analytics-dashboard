# Swiggy Sales Analytics Dashboard

## Project Overview
This interactive Excel dashboard analyzes Swiggy sales data to provide business insights on orders, revenue, customer behavior, and top-performing categories.

## Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Conditional Formatting
- Excel Formulas (SUMIFS, COUNTIFS, IF, etc.)

## Dashboard Features
- Total Orders
- Total Revenue
- Average Order Value
- Top Selling Categories
- City-wise Sales Analysis
- Monthly Sales Trend
- Payment Method Analysis
- Interactive Filters using Slicers

## Key Insights
- Identified top-performing cities and food categories.
- Analyzed monthly sales trends.
- Compared payment methods and customer ordering patterns.
- Built an interactive dashboard for quick business decision-making.
